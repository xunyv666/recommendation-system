关于本系统

课程设计

一、系统定位

本系统是一个面向电影与图书两个应用场景的通用推荐系统。 用户可选择感兴趣的领域，获得个性化推荐、查看物品详情与相似推荐， 并在算法看板中对比不同推荐模型的离线评测效果。

二、技术架构

  • 前端：原生 HTML/CSS/JS，零外部依赖，可独立部署为静态站点
  • 后端：Flask 提供 REST API，Waitress 作生产 WSGI 服务器
  • 算法层：基于开源推荐算法平台 RecBole 统一训练与评测
  • 存储：SQLAlchemy + SQLite（开发）/ MySQL（生产）
  • 部署：GitHub → Cloudflare Pages（前端）+ Cloudflare Tunnel（后端）

三、推荐流程

系统采用离线训练 + 在线查表的两段式架构：

  • 离线阶段：在历史交互上训练图卷积等模型，为每个用户预生成 Top-N 推荐并落库； 同时计算物品的内容相似度矩阵
  • 在线阶段：直接查询预计算结果，叠加内容画像召回与热度兜底， hybrid 模式再经 MMR 多样性重排，实现毫秒级响应，无需 GPU

四、算法说明

  • LightGCN：在用户-物品二部图上做线性传播，去掉非线性变换，效果好且训练快
  • SGL / NCL：引入自监督对比学习，缓解交互稀疏下的表征退化
  • ItemKNN：基于物品共现的经典协同过滤，作为强基线
  • EASE：闭式解的线性自编码器，在稀疏数据上往往强于深度模型
  • FREEDOM（本文）：多视图图融合——协同图传播 + 内容图传播，跨视图对比对齐，自适应融合
  • 基于内容：TF-IDF 文本语义 + 类别 multi-hot + 结构化特征，解决冷启动
  • 融合与重排：多路召回归一化融合，再用 MMR 做多样性重排，可选大模型生成推荐理由

五、数据集

  • MovieLens（电影，在线演示）：610 用户 / 9,724 电影 / 100,836 条评分
  • Goodbooks-10k（图书，在线演示）：10,000 图书 / 5,976,479 条评分， 演示库取交互最活跃的 4,000 名用户
  • Book-Crossing（图书，大规模对照）：22,593 用户 / 257,815 图书 / 929,723 条评分
